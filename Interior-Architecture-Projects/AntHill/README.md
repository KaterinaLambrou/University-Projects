# Ant Hill Project

## Project Description
This project explores the concepts of interior architecture through the design of an ant hill. The aim is to create a functional and aesthetically pleasing representation of an ant hill, considering various architectural elements and sustainable practices.

## Features
- Innovative design concepts
- Sustainable materials
- Functional layout
